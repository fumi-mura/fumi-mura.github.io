Web サイト制作Websites

Next.js を中心としたフロントエンドから、Vercel / Cloudflare でのホスティング、Supabase でのバックエンド、microCMS を使った更新できる仕組み、Google Apps Script による業務の自動化まで対応します。公式LINEの作成/連携も可能です。Front-end work centered on Next.js, with hosting on Vercel and Cloudflare, back-ends on Supabase, editable content via microCMS, and workflow automation with Google Apps Script. Official LINE account setup and integration are available too.

本職ではインフラエンジニアをしているため、作って終わりではなく、表示の速さ・毎月の運用費・セキュリティまで含めて設計できるのが強みです。無駄なサーバーを立てない構成を選ぶことで運用費を抑え、公開後も安心して使い続けられる状態でお渡しします。例えば、次のような工夫をしています。Infrastructure engineering is my day job, so a site isn't finished when it looks right — I design for load speed, running cost, and security as well. Choosing an architecture with no servers to babysit keeps monthly costs low and the site dependable long after launch. A few examples:

  • 表示の速さ：CDN から配信し、画像を最適化して、どこからでも速く表示します
  • 運用費：アクセス量に合ったスペックのサーバーを選び、過剰な構成にしません
  • 運用費：静的配信やサーバーレスを活用し、アクセスが少ない時期の費用をほぼゼロに抑えます
  • セキュリティ：管理画面やデータベースへのアクセスを制限し、権限は必要最小限にします
  • セキュリティ：バックアップと、問題が起きたときの復旧手順を用意します
  • Speed: served from a CDN with optimized images, so pages load fast from anywhere
  • Running cost: servers sized to your actual traffic, with no over-provisioning
  • Running cost: static hosting and serverless where possible, so quiet months cost next to nothing
  • Security: admin panels and databases locked down, with least-privilege access
  • Security: backups and a recovery plan ready in case something goes wrong
